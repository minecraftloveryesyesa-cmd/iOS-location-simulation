# 調査ステータス

最終更新: 2026-10-21

## 確認済みとして扱う情報

- Shift のソースには、接続・セッション管理と位置情報シミュレーションを行うコードがある。
- 調査メモでは `location_simulation_new`、`location_simulation_set`、`location_simulation_clear` などの FFI API が確認されている。
- ユーザーの実機報告では、Shift は LiveContainer 内で座標を変更し、他のアプリにも反映された。
- 既存の調査では、独自アプリのビルド・実機動作は未検証とされている。

## 未確認事項

- このリポジトリの独自アプリで位置情報シミュレーションが動作するか。
- 使用する FFI ライブラリの完全なアーキテクチャ構成とリンク互換性。
- iOS の今後のバージョンでも開発用サービスが同じ条件で使えるか。

## 実装上の原則

- 未実装機能を「動作する」と表示しない。
- ビルド成功・アプリ起動・接続・座標設定・解除・他アプリへの反映を別々に記録する。
- ペアリングファイルなどの認証情報をコミットしない。
