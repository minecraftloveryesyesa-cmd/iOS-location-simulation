# テスト計画

## 目的

Shift の実装を参考にした最小アプリについて、ビルド成立性・接続成立性・座標変更・解除をそれぞれ独立して確認する。UI が表示できることと、OS の位置情報シミュレーションが成功することは別の判定にする。

## 現状

- 初期版: 座標入力と範囲チェックのみ。
- 位置情報シミュレーションエンジン: 未実装。
- 独自アプリから他アプリへの反映: 未検証。

## 段階別チェックリスト

- [ ] GitHub Actions が unsigned IPA を生成する
- [ ] IPA 内にアプリの実行ファイルが含まれる
- [ ] LiveContainer で初期版を起動できる
- [ ] 使用する FFI バイナリの形式・アーキテクチャを確認する
- [ ] 接続開始時の成否とエラーを記録する（秘密情報は記録しない）
- [ ] 座標設定後、許可されたテストアプリで結果を確認する
- [ ] 解除後にシミュレーションが停止することを確認する
- [ ] 接続切断・再接続・不正な座標の挙動を確認する
